# 🎓 CampusMatch

CampusMatch is a college discovery and recommendation web application that helps students find colleges based on their admission preferences.

Students can enter their entrance exam, rank, category, preferred state, branch, and budget to explore suitable colleges.

## 🚀 Features

- 🎓 College discovery
- 🔍 Search colleges
- 🏫 Filter colleges by type and branch
- 📊 College match percentage
- 📝 Student admission profile form
- 🎯 Personalized college recommendations
- 📍 College location and details
- 💰 Fee and closing-rank information
- 🌙 Dark Mode / Light Mode
- 📱 Responsive design
- 🔐 Login page
- ⚡ React Router navigation
- 🎨 Modern UI with Tailwind CSS

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Lucide React
- Framer Motion
